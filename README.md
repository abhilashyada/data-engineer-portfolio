## Local Development

### Prerequisites

- Node.js
- npm
- Git

### Install Dependencies

```bash
npm ci
```

### Start Development Server

```bash
npm run dev
```

### Run Code Quality Checks

```bash
npm run lint
```

### Create Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
